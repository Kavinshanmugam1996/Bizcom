# Bizcom AI Risk Assessment

A structured diagnostic tool built on ISO 42001 and NIST-RMF principles — assessing organisation's AI oversight maturity across six critical dimensions.

## Features
- **50-Question Diagnostic**: Comprehensive assessment of AI governance.
- **Advanced React UI**: Beautiful dashboard with Recharts integration.
- **PDF Generation**: Instant evidence-based risk profile and prioritised action plan.

## How to Run on Your Computer

### Prerequisites
- **Git**: [git-scm.com](https://git-scm.com/)
- **Python 3.9+**: [python.org](https://python.org/)

### Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Kavinshanmugam1996/Bizcom.git
   cd Bizcom/Bizcom
   ```

2. **Create and Activate a Virtual Environment**
   ```bash
   # Mac/Linux:
   python3 -m venv venv
   source venv/bin/activate

   # Windows:
   python -m venv venv
   venv\Scripts\activate
   ```

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Application**
   ```bash
   python3 main.py
   ```

5. **Access the App**
   Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser.
